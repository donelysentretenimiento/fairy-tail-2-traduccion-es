# Guía de estilo — español de España

- Redacción natural y breve, adecuada al ancho de una interfaz.
- Mantener consistencia entre etiquetas, órdenes, explicaciones y nombres propios.
- Conservar literalmente identificadores, variables, marcadores y códigos.
- No traducir automáticamente nombres de personajes, gremios, magia, técnicas o Fairy Heart.
- Usar el glosario como propuesta hasta contrastar cada término con su contexto/lore.
- Marcar como pendiente todo texto sin revisión lingüística; no inferir calidad por diferencia con el inglés.
- Caracteres obligatorios por verificar visualmente: á é í ó ú, Á É Í Ó Ú, ñ Ñ, ü Ü, ¿ ¡ « ».
- Usar provisionalmente `Lácrima` en interfaz para mantener el avance heredado; la referencia comunitaria alterna `Lacrima` y `Lácrima`, por lo que la decisión queda registrada y no se aplicará como sustitución ciega.
- Mantener `Dragon Slayer`; usar `Imperio Alvarez`. Para `Spriggan 12`, decidir entre el nombre propio y `12 Escudos de Spriggan` según el contexto y espacio disponible.
